# 记忆与情绪系统说明

## 目录结构

```
memory/
├── char_state.json      # 心理层：激素 + 情绪状态
├── user_state.json      # 关系层：用户偏好 + 信任度
├── memories.json        # 情景层：向量记忆库
├── important.json       # 重要事件列表
└── diary/               # 日记层：每天的对话摘要
    ├── 2026-09-20.md
    └── ...
```

---

## 一、四层记忆系统

### 1. 心理层（char_state.json）

**存什么**：
- 四个神经激素数值（0-1）
- 当前情绪 + 强度
- 认知状态（在想什么）

**字段说明**：
| 字段 | 含义 | 默认值 |
|------|------|--------|
| `oxytocin` | 催产素：亲密感/信任 | 0.70 |
| `dopamine` | 多巴胺：开心/兴奋 | 0.60 |
| `cortisol` | 皮质醇：压力/紧张 | 0.10 |
| `energy` | 能量：精力/疲劳 | 0.85 |
| `primary_emotion` | 当前情绪 | neutral |
| `emotion_intensity` | 情绪强度（1-5） | 3 |
| `active_agenda` | 现在在想什么 | Observing... |

**怎么改**：
- 改默认值：`src/memory.py` 里的 `_default_char_state()`
- 改激素变化速度：`tick_hormones()` 里的衰减系数

---

### 2. 关系层（user_state.json）

**存什么**：
- 信任等级
- 用户的偏好/习惯（最多25条）
- 共同的重要时刻（最多10条）

**字段说明**：
| 字段 | 含义 |
|------|------|
| `trust_level` | 信任等级（Neutral/Developing Trust/Deeply Bound...） |
| `preferences_habits` | 用户偏好列表 |
| `shared_milestones` | 共同里程碑列表 |

**怎么改**：
- 改默认值：`src/memory.py` 里的 `_default_user_state()`
- 改最大条数：`_apply_patch()` 里的 `[-25:]` 和 `[-10:]`

---

### 3. 情景层（memories.json）

**存什么**：
- 每轮对话的摘要
- 每段摘要的向量（用于语义检索）
- 时间戳 + 批次号

**工作流程**：
1. 对话结束后，小模型生成 50 字摘要
2. 用本地向量模型（bge-reranker-v2-m3）把摘要转成向量
3. 存进 memories.json
4. 下次对话时，把当前对话也转成向量，找最相似的 5 条

**怎么改**：
- 改向量模型：`_get_embedding_model()` 里的 `model_name`
- 改检索条数：`build_memory_prompt()` 里的 `top_k=5`
- 改摘要长度：`extract_memory_patch()` 里的 prompt

---

### 4. 日记层（diary/）

**存什么**：
- 每天一个 md 文件
- 每轮对话的摘要按时间存进去

**怎么改**：
- 改日记格式：`save_diary_entry()`
- 改加载天数：`build_memory_prompt()` 里的 `days=2`

## 二、神经激素情绪系统

### 四个激素的变化逻辑

| 激素 | 增加 | 减少 |
|------|------|------|
| 催产素 | 用户说话 +0.15 | 没人理每分钟 -0.008 |
| 多巴胺 | 用户说话 +0.10，新事件 +0.08 | 每分钟 -0.004 |
| 皮质醇 | （模型输出） | 每分钟 -0.010 |
| 能量 | 每分钟自动恢复 +0.025 | 宠物说话 -0.06 |

### 情绪是怎么算出来的

不是模型猜的，是根据激素值自动算的：

```python
scores = {
    "melancholy": (1 - oxytocin) * 1.6  # 催产素低 → 忧郁
    "concerned":  cortisol * 1.4        # 皮质醇高 → 担心
    "curious":    dopamine * 1.1        # 多巴胺高 → 好奇
    "warm":       oxytocin * 0.9        # 催产素高 → 温暖
    "excited":    (dopamine + oxytocin) * 0.7  # 两个都高 → 兴奋
    "relaxed":    (1 - dopamine) * 0.8  # 多巴胺低 → 放松
    "playful":    dopamine * 0.6 + (1 - cortisol) * 0.4  # 调皮
    "sleepy":     (1 - energy) * 1.5    # 能量低 → 想睡觉
}
```

取分数最高的那个作为当前情绪。

### 触发的行为

- 能量 < 0.05 → 想睡觉
- 催产素 < 0.25 → 感到孤独
- 单击桌宠 → 显示状态气泡

## 三、对话流程

### 每次对话前（塞给模型的内容）

1. **心理层**：当前情绪 + 四个激素数值
2. **关系层**：信任等级 + 用户偏好 + 重要时刻
3. **情景层**：最相似的 5 条记忆
4. **重要事件**：最近 3 个重要事件
5. **日记层**：最近 2 天的日记

### 每次对话后（自动更新）

1. 跑一次小模型，提取记忆补丁（JSON 格式）
2. 应用补丁：
   - 更新激素数值
   - 计算新情绪
   - 加新的用户偏好
   - 存对话摘要到记忆库
   - 写进日记

## 五、常见修改

### 想改情绪衰减速度
打开 `src/memory.py`，找到 `tick_hormones()`：
- `0.008` → 催产素每分钟衰减量
- `0.004` → 多巴胺每分钟衰减量
- `0.010` → 皮质醇每分钟衰减量
- `0.025` → 能量每分钟恢复量

### 想改对话后提取记忆的频率
打开 `chat_window.py`，找到 `_on_done()`，注释掉 `extract_memory_patch(...)` 那行。

### 想改向量记忆检索条数
打开 `src/memory.py`，找到 `build_memory_prompt()`，把 `top_k=5` 改成你想要的数。

### 想清空所有记忆
删除 `memory/` 文件夹就行，下次启动自动重建。

## 六、Token 消耗

每次对话多塞给模型约 **800 token**：
- 心理层 + 关系层：约 200 token
- 情景层（5条记忆）：约 500 token
- 日记层：约 100 token

每次对话后多跑一次小模型：
- 输入：约 300 token
- 输出：约 150 token

**一天聊 100 次，多花约 1 块钱**（硅基流动价格）。
